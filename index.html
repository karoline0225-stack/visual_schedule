<SLP루다쌤이 만든 모바일 스케줄보드>

스마트폰으로 간편하게 일과를 관리하고 아이의 성취감을 높여주는 시각적 스케줄 보드입니다.

1. 스케줄 분류하기 (탭 선택)

상단의 요일 버튼을 눌러 날짜별로 스케줄을 관리하세요. 매일 반복되는 일상은 맨 앞의 '한번' 탭에 넣어두면 편리합니다.

2. 📸 사진 여러장 추가하기

[사진 여러장 추가하기] 버튼을 눌러 여러 장의 사진을 동시에 고르거나 촬영해 추가하세요. 대상이 잘 보이고, 친숙한 사진일수록 좋습니다.

3. 스케줄 카드 관리

  • 🎯 끝: 일과를 마치면 눌러 '끝 박스'로 이동시킵니다.
  • ▲ / ▼: 카드의 순서를 위아래로 바꿉니다.
  • ✏️ 수정 / 🗑️ 삭제: 이름을 바꾸거나 카드를 지웁니다.

4. 📥 끝 박스 기능

'끝' 누른 일정은 아래 끝 박스에 모이며, 🔄 끝난 스케줄 모두 되돌리기는 끝 박스에 모인 모든 스케줄을 끝 박스에서 다시 꺼내어 스케줄로 등록할 수 있습니다.

5. 🖨️ 인쇄하기

상단 🖨️ 인쇄 버튼을 통해 A4 세로 형식으로 깔끔하게 출력할 수 있습니다.

💡 데이터 저장 안내: 데이터는 사용 중인 기기(브라우저)에 안전하게 저장됩니다. 🗑️현재 탭 스케줄 전체 리셋하기를 누르면 해당 탭의 데이터는 삭제됩니다. 브라우저 캐시 삭제 시 데이터가 초기화될 수 있으니 유의하세요.
